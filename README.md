# Tax Calculator UI

A simple, fast, and modern tax calculator.

## Features
- Comparison between Old and New Tax Regimes.
- Metro city HRA calculation.
- Provident Fund (PF) inclusion/exclusion.
- Standard Deduction and Section 80C/80D support.
- Built with React + TypeScript + Pico CSS.

## Getting Started
1. `npm install`
2. `npm run dev`
